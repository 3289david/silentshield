How it works
Five layers of invisible detection

Every visitor is silently scored in real-time. Humans pass instantly. Bots get blocked — or silently fed fake success.

👁️

Page Entry

We record when the user enters, their browser fingerprint, screen size, and hardware concurrency — headless browsers stand out immediately.

+10 Real browser detected
-40 Headless Chrome
-50 WebDriver flag set
🖱️

Behavior Score

Humans move mice, scroll, and click. Bots jump straight to submit. We track every interaction event without affecting performance.

+20 Mouse movement detected
+10 Scroll events
-25 No mouse, no scroll
⌨️

Input Score

Humans type with natural variance and rhythm. Bots fill forms in milliseconds with machine-perfect timing. We detect both.

+20 Natural typing speed
+5 Backspacing (mistakes)
-40 Form filled in <500ms
🌐

Environment Score

Cloud IPs, datacenter subnets, and unusual environments are weighted. Real users browse from home and mobile networks.

+8 Normal screen size
+7 Browser plugins present
-30 AWS/GCP/Azure IP
🎯

Final Score

All signals combine into a 0–100 score. Humans pass transparently. Bots are blocked — or shown a fake success message to waste their time.

70–100 Human — pass
45–69 Suspicious — flag
0–44 Bot — block
🧠

AI Learning

Every 10 minutes, SilentShield analyzes recent bot attempts and automatically updates detection patterns — it learns what the bots do.

+auto New bot UA learned
+auto Timing patterns updated
+auto Confidence scores refined
Integration
Works in 2 lines of code

Drop the script tag, add data-silentshield to your form. Done.

✓ No CAPTCHA widgets to render
✓ No Google reCAPTCHA dependencies
✓ Works with any HTML form
✓ Server-side verification in 1 API call
index.html
<!-- Step 1: Add the script -->
<script
  src="https://cdn.silentshield.io/v1/sdk.js"
  data-silentshield-key="pk_your_key"
></script>

<!-- Step 2: Tag your form -->
<form data-silentshield action="/submit">
  <input type="text" name="name" />
  <button type="submit">Send</button>
</form>
server.js — verify on your backend
const res = await fetch(
  'https://api.silentshield.io/api/verify',
  {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      token: req.body._ss_token,
      secret: 'sk_your_secret'
    })
  }
);

const { valid, score, verdict } = await res.json();
// { valid: true, score: 92, verdict: 'human' }

if (!valid) return res.status(403).send('Bot detected');
Features
Everything you need to stop bots

Built for developers who want protection without the headache.

🕵️

Fake Success Mode

When a bot is blocked, we show it "Successfully submitted!" — it never knows it failed. Bots waste time retrying while your data stays clean.

🍯

Smart Honeypot

Hidden fields are generated with randomized names like phone2, contact_alt — rotated so bots can't learn to skip them.

🧠

10-Minute Learning

Every 10 minutes, the system analyzes recent bot patterns and updates its detection weights automatically. It gets smarter the more it sees.

🚫

AI Spam Filter

Form submissions are scanned for spam keywords — SEO offers, crypto investment, backlink deals — and auto-blocked at the content level.

🤖

AI Agent Detection

Detects Playwright, Puppeteer, Selenium, Browser Use, and OpenAI Operator-style agents via WebDriver flags, timing patterns, and environment checks.

📊

Real-time Dashboard

See live traffic, blocked bots, threat types, and country breakdowns. Visualize exactly what SilentShield is stopping for you.

🔑

No API Key Required*

The free tier works without registration. Add your domain for analytics and to track monthly usage. *Anonymous mode available for quick testing.

🔒

Privacy First

No cookies set. No user data sold. IPs are hashed. No Google dependencies. GDPR-friendly by design — your users are yours.

🌍

Open Source SDK

The JS SDK is MIT licensed and on GitHub. Inspect every line of code running on your users' browsers. No black boxes.

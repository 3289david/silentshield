8-layer invisible analysis

How SilentShield detects bots

Each layer adds signal. Combined, they catch 99%+ of automated traffic — without ever annoying real users.

🖱️

Mouse Path Entropy

Humans move mice in natural curves with random micro-tremors. Bots move in straight lines or scripted arcs. SilentShield measures the angle-change variance across every recorded mouse event. Low variance = bot. Threshold: <0.3 rad/event = suspicious.

Weight: 20pts
🔢

Proof of Work (SHA-256)

The browser must solve a SHA-256 hashcash puzzle (find a nonce where SHA256(challenge+nonce) starts with 000) before submitting. Headless browsers solve it but the timing reveals automation. Humans don't even notice — it runs in a background Web Worker.

Weight: 15pts
🎨

Canvas Fingerprinting

Renders a gradient + text to an offscreen canvas and reads the last 64 bytes of the PNG. Real browsers produce unique renders due to GPU, font rendering, and anti-aliasing differences. Headless Chromium produces near-identical output every time. Byte-level variance is the signal.

Weight: 15pts
🌐

WebGL Renderer Detection

Calls WEBGL_debug_renderer_info to read the GPU string. Headless bots report SwiftShader, llvmpipe, Mesa, or ANGLE — software renderers that only exist in virtual environments. Real browsers report real GPU names (NVIDIA, AMD, Apple M-series).

Weight: 10pts
🔊

Audio Fingerprinting

Creates a 2048-point FFT of an OscillatorNode through an AnalyserNode. Real browsers show characteristic frequency patterns from their audio stack. Headless environments produce flat, near-zero output or throw errors. The frequency distribution becomes a fingerprint.

Weight: 10pts
⌨️

Keyboard Biometrics

Tracks inter-keystroke timing intervals and computes their variance. Humans have natural timing jitter (std dev >50ms). Automated form fillers inject keystrokes at uniform intervals or all at once (variance ≈ 0). Paste events, backspace rate, and tab navigation are also scored.

Weight: 10pts
🍯

Rotating Smart Honeypot

Injects a CSS-hidden field with one of 20 rotating names (website, homepage, company, url…). The field name rotates to defeat bot databases. Real users never fill it (it's invisible). Bots that auto-fill all fields expose themselves immediately. Triggered = automatic bot verdict.

Weight: -50pts if triggered
🌍

Environment & Behavior

Checks 12+ environment signals: navigator.webdriver, permission API state, plugin count, screen dimensions, touch events, timezone consistency, battery API, form fill timing, scroll behavior, and network connection type. Each is weighted independently.

Weight: 20pts combined

<?php
$token = $_POST['silentshield_token'] ?? '';

# Python / FastAPI / Flask backend
import requests

def verify_token(token: str) -> bool:
    resp = requests.post(
        "https://silentshield.krl.rk/api/verify",
        json={"token": token}
    )
    data = resp.json()
    return data.get("valid", False)

# In your route:
if not verify_token(request.json["token"]):
    raise HTTPException(status_code=403, detail="Bot detected")

Self-hosting

Own your
infrastructure.

Deploy SilentShield to any Linux VPS in under 5 minutes. One command. Full control.

1
Get a VPS Any Ubuntu 22.04 server works. DigitalOcean, Hetzner, Linode — $5/month is enough.
2
Run the deploy script One command installs Node.js, PM2, clones the repo, builds the SDK, and starts the server.
3
Add nginx + SSL The script prints the exact nginx config and certbot command. Takes 2 minutes.
4
Point your SDK at it Change apiUrl to your domain. Done.
bash — Ubuntu 22.04 VPS 
# One-command deploy
curl -fsSL \
  https://raw.githubusercontent.com/3289david/silentshield/main/deploy.sh \
  | bash

# That's it. Script will print:
✓ SilentShield is running!
  URL: http://YOUR_IP:3000

# Then set up SSL:
apt install nginx certbot python3-certbot-nginx
certbot --nginx -d your-domain.com

# Point your SDK:
new SilentShield({
  apiUrl: 'https://your-domain.com'
});
Requirements: Ubuntu 22.04+, 512MB RAM, port 80/443 open. Node.js 20 is installed automatically.
